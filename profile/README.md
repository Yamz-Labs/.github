# Yamz Labs

We run large open models on one small machine: a 128 GB AMD Ryzen AI Max+ 395 (Strix Halo). We publish the engine and EXL3 quantisations of Qwen3.8-Flash-Next and GLM-5.3-Flash, with quality measured against the official FP8 weights. Every number has a date and a protocol; what we did not measure, we say so. Only gfx1151 with ROCm is tested.

- **Website:** [yamzlabs.com](https://yamzlabs.com)
- **Engine:** [kyojin](https://github.com/Yamz-Labs/kyojin), built on ExLlamaV3, with a ROCm path for gfx1151.
